# Bienvenida

Este es el **jardín digital** de *jd26*: un conjunto de páginas que crecen con el tiempo.

## Madurez de las páginas

- 🌱 **Semilla**: idea inicial, apenas esbozada.
- 🌿 **Brote**: en desarrollo.
- 🌳 **Árbol**: completa.

## Añadir una página

1. Copia `bienvenida.html` con otro nombre, por ejemplo `mi-nota.html`, y cambia el título.
2. Escribe el contenido en `markdown/mi-nota.md` (mismo nombre).
3. Añade su ficha en `index.html` copiando un `<li class="pagina">`.

## Verlo en local

```bash
python -m http.server 8000
```

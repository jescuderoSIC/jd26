Cómo funciona el blog

Escribes en un editor limpio, sin distracciones. Al pulsar Publicar, el editor genera una página HTML normal para cada entrada y actualiza la portada del blog. No hay servidor ni base de datos: el blog son archivos en la carpeta claude-clon-substack.

Qué hay en la carpeta

claude-clon-substack/ ├── editor.html ← donde escribes (no se enlaza desde las entradas) ├── instrucciones.html ← esta página ├── index.html ← portada del blog; se regenera al publicar ├── posts.json ← datos del blog y lista de entradas publicadas ├── plantillas.js ← diseño de las páginas generadas ├── posts/ │ └── mi-entrada.html ← una página por entrada publicada └── imagenes/ └── foto-x1y2z3.jpg ← imágenes subidas desde el editor

Las carpetas posts/ e imagenes/ se crean solas la primera vez que publicas o subes una imagen con la carpeta conectada.

No hace falta editar a mano index.html, posts.json ni las páginas de posts/: el editor las vuelve a escribir cada vez que publicas.

Primeros pasos

  1. Abre el editorAbre editor.html en Chrome o Edge de escritorio. Funciona con doble clic, pero va mejor con el servidor local (en la carpeta de jd26 ejecuta python -m http.server 8000 y entra en http://localhost:8000/claude-clon-substack/editor.html).
  2. Rellena los ajustesPulsa el engranaje ⚙ y pon el nombre del blog, una descripción corta, tu firma y el color principal. Si no lo haces, el blog se llama «Mi blog» y las entradas salen sin autor.
  3. Conecta la carpetaPulsa Conectar carpeta y elige claude-clon-substack. El navegador te pedirá permiso para editar archivos: acéptalo. Desde ese momento, publicar escribe los archivos directamente en la carpeta. El permiso se recuerda; si el navegador lo olvida, el botón dice Reconectar carpeta.
  4. Escribe y publicaPon un título, escribe y pulsa Publicar. La entrada aparece en la portada del blog.

Escribir una entrada

El editor se ve igual que la entrada publicada. Arriba están, en este orden:

  • Imagen de portada (opcional). Sale encima del texto y como miniatura en la portada del blog.
  • Título. Es obligatorio para publicar. Intro salta al subtítulo.
  • Subtítulo (opcional). Se muestra bajo el título y en la portada del blog. Intro salta al texto.
  • Firma: tu nombre y la fecha, que se toman de los ajustes.

Pegar texto de otros sitios

Puedes pegar desde Word, Google Docs o cualquier web. El editor conserva la estructura (títulos, negritas, cursivas, listas, citas, enlaces e imágenes) y descarta el resto: fuentes, colores, tamaños, tablas y estilos raros. Así todas las entradas tienen el mismo aspecto.

  • Si pegas un enlace con texto seleccionado, el texto se convierte en enlace.
  • Si pegas un enlace de YouTube en una línea vacía, se inserta el vídeo.
  • Dentro de un bloque de código, lo que pegas entra tal cual, sin formato.

Bloques: Texto, Markdown y HTML

Una entrada es una sucesión de bloques, y cada uno puede ser de un tipo distinto. Se combinan en el orden que quieras: un párrafo con formato, una sección escrita en Markdown, un artefacto HTML, más texto…

TipoCómo se escribe
TextoCon formato, como en un procesador de textos, usando la barra de formato.
MarkdownSe ve ya convertido. Al pulsarlo aparece el texto en Markdown para editarlo, y al salir del bloque se vuelve a ver el resultado.
HTMLCódigo HTML que se ve funcionando en un marco aislado. Se cambia con Editar código. Ver Código y HTML.
  • El selector Bloque: Texto · Markdown · HTML, encima de la barra de formato, indica el tipo del bloque en el que estás. Pulsando otro tipo, el bloque se convierte. Ctrl+M alterna entre Texto y Markdown. Al convertir un bloque HTML en otro tipo se pierden sus estilos y scripts, y el editor pide confirmación.
  • Al pasar el ratón por un bloque aparecen sus controles: ↑ ↓ para moverlo y ✕ para borrarlo. Debajo aparece Añadir bloque: + Texto · + Markdown · + HTML, que añade un bloque nuevo justo detrás. Tras el último bloque estos botones se ven siempre.
  • La barra de formato solo funciona en los bloques de Texto; en los demás aparece apagada.
  • Dos bloques de Texto seguidos se unen en uno al volver a abrir la entrada; el resultado es el mismo.

Imágenes y vídeos

Imágenes

Hay tres formas de añadir una imagen: el botón Imagen (eliges un archivo o pegas su dirección), pegarla con Ctrl+V, o arrastrarla al texto. Debajo de cada imagen puedes escribir un pie de foto opcional.

Para quitar una imagen, púlsala (queda marcada) y pulsa Supr o Retroceso.

Dónde acaba el archivo depende de si la carpeta está conectada:

SituaciónQué pasa con la imagen
Carpeta conectadaSe copia a imagenes/ con un nombre único. Si es muy grande, se reduce a 2400 px. La página la enlaza como un archivo normal.
Sin carpetaSe reduce a 1600 px y va incrustada dentro de la propia página. Funciona, pero la página pesa más y el navegador puede quedarse sin espacio para guardar el borrador.
Por dirección (https://…)Se enlaza la imagen de esa web. Si la web la borra o la mueve, dejará de verse.

Conecta la carpeta antes de añadir imágenes. Las que se añadieron sin carpeta se quedan incrustadas aunque la conectes después.

Vídeos

De momento solo se admiten vídeos de YouTube. Usa el botón Vídeo o pega el enlace en una línea vacía. En el editor verás la miniatura; en la entrada publicada, el reproductor (con youtube-nocookie.com, que no pone cookies hasta que se pulsa reproducir).

Código y HTML

Bloques de código

Crea un bloque con Bloque de código en el selector de estilo o escribiendo ``` y un espacio al principio de un párrafo. Con el cursor dentro, elige el lenguaje en el selector que aparece al lado. Tab añade sangría.

En la entrada publicada, los colores del código se añaden con highlight.js, que se adaptan al modo claro y oscuro. Cada bloque lleva una cabecera con el nombre del lenguaje y un botón Copiar. Con el lenguaje en Automático se intenta adivinar, pero si el fragmento es corto puede quedarse sin colores. Elegir el lenguaje es más seguro.

Bloques HTML (artefactos de Claude)

Para crear uno, usa + HTML en «Añadir bloque», o el botón Bloque HTML de la barra, que corta el texto donde está el cursor. Se abre un cuadro donde pegas el código: una página completa (como un artefacto de Claude) o un fragmento. En el editor ves cómo queda; con Editar código lo cambias y con ✕ lo borras.

  • Se muestra dentro de un marco aislado: sus estilos y scripts funcionan, pero no afectan al resto de la página ni pueden leer nada del blog.
  • La altura se ajusta sola al contenido. Si el contenido ocupa toda la pantalla (usa 100vh) o la altura no queda bien, pon una altura fija.
  • Usar todo el ancho lo saca de la columna de texto, hasta 1100 px. Viene bien para juegos, gráficos o tableros.
  • Dentro del marco no funciona localStorage. Si un artefacto guarda datos así, dará error o no recordará nada.
  • Las librerías que el HTML cargue de internet (CDN) funcionan con normalidad.

Dónde se guarda lo que escribes

Mientras escribes, todo se guarda solo en el navegador, medio segundo después de cada cambio. Arriba se ve el estado: «Guardado · 350 palabras · 2 min». Puedes cerrar la pestaña y volver: el editor abre la última entrada en la que estabas.

Lo que hay en el navegador no está en la carpeta hasta que publicas. Si borras los datos del navegador o usas otro ordenador, los borradores no estarán; las entradas publicadas, sí, porque son archivos.

Un borrador muy largo con muchas imágenes incrustadas puede no caber en el navegador. Si pasa, arriba aparece un aviso ⚠. Conecta la carpeta para que las imágenes vayan a archivos.

Publicar

Pulsa Publicar. Se abre un cuadro con dos datos:

  • Dirección de la página: el nombre del archivo, sacado del título (¿Qué tal, España? → posts/que-tal-espana.html). Solo admite minúsculas, números y guiones. Puedes cambiarlo.
  • Fecha de publicación: hoy, salvo que pongas otra. La portada ordena las entradas por esta fecha.

Con la carpeta conectada

Se escriben tres cosas a la vez: posts/<dirección>.html, index.html (la portada con la lista de entradas) y posts.json. El aviso que aparece tiene un botón Ver que abre la entrada.

Sin carpeta (Firefox, Safari o sin permiso)

Se descargan esos tres archivos. Cópialos tú:

  • <dirección>.html → dentro de claude-clon-substack/posts/
  • index.html y posts.json → dentro de claude-clon-substack/, sustituyendo los que haya

Cambiar una entrada ya publicada

Edítala y pulsa Publicar otra vez (el botón dirá Actualizar). Si cambias la dirección, se borra el archivo antiguo y se crea el nuevo. Ojo: los enlaces que alguien tuviera a la dirección antigua dejarán de funcionar.

Vista previa

Vista previa abre en otra pestaña la entrada tal como quedará, sin publicar nada.

Gestionar las entradas

El botón Entradas abre la lista de todo lo que tienes, con su estado:

EstadoSignifica
BorradorSolo está en el navegador; no se ha publicado nunca.
PublicadaLa página publicada coincide con lo que tienes en el editor.
Cambios sin publicarEstá publicada, pero la has cambiado después. Pulsa Actualizar para que los cambios salgan en el blog.
  • + Nueva entrada empieza una entrada en blanco. Si la dejas vacía, no se guarda.
  • La papelera de un borrador lo borra del navegador (no se puede deshacer).
  • La papelera de una entrada publicada la retira del blog: borra su archivo de posts/ y la quita de la portada. El texto se queda en el editor como borrador, por si quieres volver a publicarla.
  • Abrir un .html publicado… carga en el editor una entrada a partir de su archivo. Sirve para seguir editando en otro ordenador o en otro navegador.

Cada página publicada lleva dentro sus datos (título, subtítulo, portada, fecha y dirección), así que el editor puede reconstruir la entrada leyendo la propia página.

Ajustes del blog

En el engranaje ⚙ cambias el nombre, la descripción, el autor y el color (enlaces, citas y el círculo de la firma). Al guardar, la portada del blog se actualiza enseguida.

Las entradas ya publicadas tienen el nombre y el color antiguos escritos dentro. Para cambiarlas, pulsa Regenerar en el aviso o Regenerar todas las páginas en los ajustes: el editor vuelve a escribir cada entrada con los ajustes nuevos. Necesita la carpeta conectada.

Regenerar también sirve si cambias el diseño en plantillas.js.

Subirlo a internet

El blog son archivos estáticos, así que vale cualquier alojamiento de páginas. Si publicas jd26 con GitHub Pages, basta con subir la carpeta al repositorio.

git add claude-clon-substack
git commit -m "Nueva entrada en el blog"
git push

Al cabo de un minuto, el blog estará en …/jd26/claude-clon-substack/. Sube también la carpeta imagenes/ si has añadido imágenes.

Publicar escribe siempre en la carpeta de tu ordenador, aunque abras el editor desde la web publicada. Lo publicado no aparece en internet hasta que haces git push.

Problemas frecuentes

No sale el botón «Conectar carpeta»

Tu navegador no permite escribir en carpetas (Firefox, Safari, móviles). Usa Chrome o Edge de escritorio, o publica descargando los archivos.

Al abrir una entrada publicada dice que no puede

Con el editor abierto con doble clic, el navegador no deja leer otros archivos. Conecta la carpeta, usa el servidor local, o usa Abrir un .html publicado….

Una imagen no se ve en el editor

Las imágenes de imagenes/ se buscan junto a editor.html. Si conectaste una carpeta distinta de claude-clon-substack, las imágenes se guardan allí y el editor no las encuentra. Conecta la carpeta correcta.

«Ya hay otra entrada publicada en esa dirección»

Dos entradas no pueden tener el mismo archivo. Cambia la dirección en el cuadro de publicar.

Las SVG no se pueden añadir

Sin carpeta, las imágenes SVG no se incrustan, por seguridad. Conecta la carpeta y se guardarán como archivo.

He cambiado de ordenador y no veo mis borradores

Los borradores viven en el navegador donde los escribiste. Lo publicado sí está en la carpeta: ábrelo desde Entradas con la carpeta conectada.
